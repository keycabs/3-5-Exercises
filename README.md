# 3-5 Exercises: User Input

This lesson reviewed how Java programs receive and process user input.

In `Input01`, I imported `JOptionPane` and used `showInputDialog()` to collect input in a dialog box. The input was returned as a `String`. I used `Integer.parseInt()` to convert the `String` into an `int`, which allowed me to perform addition with it. I also practiced nesting the input dialog inside `Integer.parseInt()` on one line.

In `Input03`, I imported the `Scanner` class and created a scanner using `System.in`. I used `nextInt()` to read three integers from the terminal, added them together, and printed the result. I also learned to close the scanner when the program was finished using `scanner.close()`.

Most of these concepts were familiar to me, but the exercises gave me more practice with imports, data types and user input. I needed some help understanding how to combine the dialog and conversion into one line and how to properly finish the scanner program.
